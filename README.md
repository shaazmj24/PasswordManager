# Password Manager Project

A *Java-based desktop application* for securely storing and managing passwords. Built with *Swing* for the UI and *JSON-based persistence*, this password manager provides essential features like encryption, search, and multi-account support.

## Features 
- Securely store and retrieve passwords for multiple accounts
- Encrypt and decrypt stored passwords
- Search accounts by name
- Add, update, and delete account entries
- Save and load password data from file
- Simple, user-friendly graphical interface (built with Java Swing)

## Technologies Used
- Java 17
- Swing (Java GUI Toolkit)
- JSON for persistent storage
- Java IO / File handling
